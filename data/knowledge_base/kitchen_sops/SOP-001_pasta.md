# SOP-001 Pasta Cooking Procedure
1. Confirm pasta type and portion from the approved recipe.
2. Use clean designated cookware.
3. Boil water, add salt per kitchen standard, add pasta and stir.
4. Cook to the approved recipe texture, following package guidance.
5. Reserve pasta water if required, drain and finish as specified.
6. Report quality issues to the kitchen supervisor.
